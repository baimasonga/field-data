# Feature specifications

## Semantic Photo-to-Database

Extract domain-specific structured values from images: quantities, labels, condition, defects, materials, dimensions, or presence. Ground every value to visible evidence and let users correct it.

## Object Becomes the Form

Recognize a candidate asset and propose the relevant inspection module. Confirm identity/type when uncertain, then combine common questions with asset-specific checks. Prevent a wrong classifier from hiding required safety questions.

## Questionless Survey Mode

Capture guided video, imagery, voice notes, and sensor context; populate a draft structured inspection; then ask only unresolved questions. Keep a clear distinction between observed, narrated, inferred, and confirmed values.

## Voice-First Conversational Collection

Track which canonical variables have been answered during an approved conversation. Use constrained extraction, confirmation for critical values, interruption recovery, local-language support, and a visible transcript/edit path where consent allows.

## Proof-of-Life Capture

Use nonce-bound motion or scene prompts and continuity checks to reduce media reuse. Provide nonvisual alternatives and avoid overstating synthetic-media detection.

## Offline Computer Vision

Package quantized models with signed version metadata, hardware capability checks, battery/thermal limits, and rollback. Log inference quality without uploading unnecessary media.
