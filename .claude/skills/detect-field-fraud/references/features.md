# Feature specifications

## Data DNA

Learn the structural signature of authentic work from timing, edits, answer transitions, routes, media, missingness, and project context. Compare within appropriate strata; never use a single universal norm.

## Collusion Detection

Build a temporal heterogeneous graph across collectors, devices, respondents, locations, media, phone identifiers, and submissions. Surface explainable subgraphs and repeated motifs; protect against guilt by association.

## Synthetic Respondent Detector

Combine identity reuse, improbable household structures, spatial clustering, repeated contact patterns, sequence regularity, answer similarity, and absent corroboration. Support legitimate shared phones and naming conventions.

## Questionnaire Fingerprinting

Model interaction patterns such as option sequences, correction order, grid timing, text phrases, and navigation behavior. Use it to detect repeated fabrication patterns, not to covertly identify individuals beyond the authorized account context.

## AI Contradiction Hunter

Translate the form schema and answers into constrained facts, then detect semantic inconsistencies. Return the conflicting fields, explanation, severity, and a proposed review question. Use deterministic checks before generative reasoning.

## Self-Designing Back-Checks

Select the smallest, highest-information set of records subject to geography, budget, safeguarding, independence, and fairness constraints. Generate a focused back-check instrument tied to suspicious claims.

## Invisible Cross-Validation

Infer the same concept from independent questions or evidence without simply repeating wording. Version the logic, vary safe question paths, and test that the mechanism does not confuse respondents.
