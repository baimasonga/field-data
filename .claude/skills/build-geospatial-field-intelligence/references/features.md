# Feature specifications

## Satellite Witness

Compare a field claim—crop, structure, flood, land cover, road, or boundary—with temporally relevant imagery. Return supporting, conflicting, inconclusive, or unavailable evidence with reason codes.

## Survey-from-Space

Detect candidate changes first, cluster and prioritize them, then create verification assignments with map context, navigation, evidence request, and safe uncertainty wording. Track whether field outcomes confirm or refute the model.

## Uncertainty Map

Represent knowledge weakness using data age, spatial coverage, sample representation, positional accuracy, evidence quality, model uncertainty, and verification coverage. Let managers inspect the component behind each area.

## Reality Change Detector

Compare time-indexed observations from satellite, aerial, street-level, or field media. Detect candidate additions, removals, damage, vegetation shifts, and condition changes while accounting for viewpoint, season, lighting, and resolution.

## Field/Satellite Feedback Loop

Use independently reviewed field results to recalibrate models and prioritize new samples. Separate training, validation, and operational feedback datasets.
