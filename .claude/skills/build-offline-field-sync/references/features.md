# Feature specifications

## Progressive Sync

Upload a small signed manifest first, then critical answers and QA metadata, then thumbnails or priority evidence, then full media. Let policy define priority and show completeness separately from receipt.

## Data Mule Networking

Allow devices to exchange opaque encrypted packages over Bluetooth, Wi-Fi Direct, local hotspot, cable, or QR-sized manifests where appropriate. Relay devices store limited, expiring packages and cannot decrypt or modify them undetected.

## Physical Data Courier Mode

Move signed encrypted bundles through supervisor phones, district laptops, or removable media while maintaining a custody ledger. Support import quarantine, malware-safe handling, verification, partial acceptance, and receipt export.

## Bandwidth-Aware Media

Generate local derivatives for triage while preserving originals. Upload according to network cost, battery, priority, consent, and evidence policy. Never substitute a derivative for the evidentiary original without marking it.

## Offline Assignment and Reference Data

Package forms, maps, cases, rosters, code lists, and permissions into signed versioned bundles with expiry and revocation behavior. Preserve access controls after download.
