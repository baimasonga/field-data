# Feature specifications

## Digital Passport for Physical Assets

Give each asset a persistent identity, geometry, classification, ownership/stewardship, installation/construction history, inspections, media, maintenance, financing, and condition changes. Support labels/QR/NFC without making the tag itself authoritative.

## Reality Change History

Compare current and previous observations, preserve detected and confirmed changes, and show who/what established each change. Separate model suggestions from approved state transitions.

## Institutional Memory Engine

Retrieve across authorized forms, reports, maps, media metadata, cases, and asset histories. Generate answers with record-level citations, time scope, uncertainty, and access enforcement.

## Counterfactual Intelligence

Support carefully specified decision questions. Distinguish correlation, prediction, quasi-experimental analysis, and causal evidence; expose assumptions, overlap, sensitivity, and uncertainty. Never label a dashboard association as an intervention effect.

## Data Freshness Decay

Compute a knowledge-freshness state based on fact volatility, elapsed time, events, source quality, season, environmental shocks, and consequences of staleness. Make the components visible.

## Evidence Expiry

Assign validity or review policies by claim type. Expiry does not erase evidence; it changes operational trust and may create re-verification work.

## Project Digital Twin

Compose entities, networks, geography, claims, states, events, scenarios, and uncertainty into a continuously updated operational model. Start with decision-specific twins, not an all-knowing simulation.
