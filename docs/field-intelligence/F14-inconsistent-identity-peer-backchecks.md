# F14: inconsistent-identity peer backchecks

Identity-inconsistency findings identify the original compared record. A linked
peer case can now use that finding for the existing neutral identity-confirmation
prompt and reviewed backcheck workflow. Cross-form targeting requires an explicit,
unambiguous matching form and instance in the finding evidence. Both source forms
must remain readable; source grant loss hides suggestions and blocks retries.
No answers or peer identifiers are included in the suggestion.

The database integration suite exercises same-form and cross-form suggestions,
reviewed form generation, dispatch, withdrawal, retries and primary-form grant
revocation. Findings are prompts for review, not evidence of misconduct by
those involved.
