# F11: same-form peer-side targeted backchecks

In an investigation, link the peer record's review case, inspect it, then choose **Prepare targeted backcheck**. Active attached shared-identity (`identity-reused:*`), similar-answer (`near-duplicate`) and repeated-location findings can now supply neutral verification prompts when that case is the finding's related record in the same form. Suggestions label **Primary record** or **Peer record**. The instrument dispatches to the linked case, not automatically to the finding's primary case.

The same fixed question templates, explicit selection/editing, reviewed response-form generation, published response-form choice and independent collector rules apply. No peer answers, identifiers, evidence or private titles enter suggestions or generated prompts. The first 20 supported findings by ID remain the bounded selection; omitted findings are counted. Dispatch remains a normal dedicated-form backcheck with the linked case's source, revision, assignee and result history. Selecting a peer finding does not establish wrongdoing or independence between respondents.

This increment is restricted to unambiguous same-form pairs with a live, non-draft primary source. Cross-form peer matches, malformed counterpart mappings, unsupported pair families, withdrawn/resolved findings and missing primary sources are excluded. Same-form sources share the locked source-form read permission. Existing manager, source read/update, response-form access, open investigation/project, active link, current case, case assignment and collector checks remain required. Eligibility is checked again under locks before form generation and new dispatch. Exact normalized retries retain their existing semantics after finding withdrawal; removing the link or source/response access still hides replay.

Tests cover each supported peer family, side labels, neutral prompt generation, dispatch to the peer case, normalized replay after withdrawal, cross-form/ambiguous/unsupported/missing-source rejection, stale write eligibility, mobile presentation and existing instrument failure/permission workflows. This is not cross-form peer targeting, multilingual/effectiveness evaluation, calibrated fraud scoring or field acceptance. Fraud intelligence and all eight areas remain partial.
